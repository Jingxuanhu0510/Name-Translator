# AI Assistance

This document explains how AI was used in *Name Translator*. I separate the AI system inside the artwork from the AI tools that supported the development process.

## 1. Google Gemini API

Google Gemini is part of the running artwork.

In the final version, Gemini reads the photographed handwritten name and returns recognised English text. It does not generate the final pseudo-character image.

## 2. ChatGPT

I used ChatGPT mainly when I was stuck on technical problems, when I needed help understanding code errors, and when I wanted to organise my writing more clearly.

I also used it to discuss interaction ideas and review technical wording.

Its suggestions were reviewed and adapted before I used them in the project.

## 3. OpenAI Codex

I mainly used Codex near the end of the project to help check the repository, organise submission files, review code comments, prepare documentation figures, and organise the GitHub and submission materials.

## 4. Student Work

The project concept, interaction design, A to Z visual mapping, glyph design, composition rules, installation decisions, and final artistic direction were all developed by me.

The generated characters come from my own JavaScript and p5.js rules after the handwriting has been recognised.
