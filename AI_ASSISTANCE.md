# AI Assistance

This document separates the AI systems used inside the artwork from the AI tools used during development.

## 1. Google Gemini API

Google Gemini is part of the artwork's running system.

In the final version, Gemini reads the photographed handwritten name and returns recognised English text. It does not generate the final pseudo-character image.

## 2. ChatGPT

ChatGPT was used as a supporting tool during development for discussing interaction ideas, explaining code errors, suggesting debugging approaches, reviewing technical wording, and helping organise written documentation.

Its suggestions were reviewed and adapted before being used in the project.

## 3. OpenAI Codex

OpenAI Codex was mainly used during the final submission stage to inspect the repository, review file organisation, improve comments, generate documentation figures from existing project rules, and prepare deployment and documentation materials.

## 4. Student Work

The project concept, interaction design, A to Z visual mapping, glyph design, composition rules, artistic decisions, installation design, and final creative direction were decided and developed by the student.

The generated characters are produced by the project's own JavaScript and p5.js rules after recognition.
