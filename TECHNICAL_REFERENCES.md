# Technical References

This file records the external services, libraries, and platforms used by Name Translator. The A to Z glyph mapping, grouping rules, square composition, rendering logic, and interaction design are original project work.

The documentation figures in `docs/images` use the current project glyph data, colour data, and structural rules through a documentation-only renderer that mirrors the live project logic. They are not generated by an image model and are not direct frame exports from the running exhibition page.

## 1. Google Gemini API

Official documentation: https://ai.google.dev/gemini-api/docs

Use in this project: reads the photographed handwriting and returns recognised English text.

Type: third-party cloud API.

## 2. Google GenAI JavaScript SDK

Official documentation: https://googleapis.github.io/js-genai/

Use in this project: server-side JavaScript SDK used to call the Gemini API from `recognition.js`.

Type: third-party SDK.

## 3. p5.js

Official documentation: https://p5js.org/reference/

Use in this project: renders the waiting scene, generated square characters, glyph animation, and Residue Archive.

Type: third-party creative coding library.

## 4. Node.js

Official documentation: https://nodejs.org/

Use in this project: JavaScript runtime for the local and deployed server.

Type: third-party runtime.

## 5. Express

Official documentation: https://expressjs.com/

Use in this project: serves the exhibition files and HTTP recognition endpoints.

Type: third-party server framework.

## 6. Socket.IO

Official documentation: https://socket.io/docs/v4/

Use in this project: passes real-time status and recognition events between the browser and server.

Type: third-party real-time communication library.

## 7. dotenv

Official documentation: https://www.npmjs.com/package/dotenv

Use in this project: loads local environment variables from `.env` during development.

Type: third-party configuration library.

## 8. qrcode

Official documentation: https://www.npmjs.com/package/qrcode

Use in this project: generates QR code data for the server's tablet connection helper.

Type: third-party utility library.

## 9. Render

Official documentation: https://render.com/docs/web-services

Use in this project: hosts the submitted Node.js web service.

Type: third-party deployment platform.
